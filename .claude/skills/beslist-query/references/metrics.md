# Metrics & KPI Calculations for Beslist.nl

This document explains how to calculate key performance metrics from Beslist.nl data.

## Revenue Metrics

### Shop Revenue (Omzet)
Revenue generated by shops through Beslist.nl.

```sql
-- From bt.cpa_outclicks_transactional
SUM(revenue_excl) AS shop_revenue

-- From bt.daily_standup_metrics_category
SUM(omzet_total) AS shop_revenue
```

### Shop Costs / Our Revenue (Marge)
What shops pay Beslist / Beslist's revenue.

```sql
-- CPR costs
SUM(COALESCE(click_revenue, 0)) AS cpr_costs

-- WW transaction costs
SUM(COALESCE(transaction_costs, 0)) AS ww_costs

-- Total shop costs / our revenue
SUM(COALESCE(click_revenue, 0)) + SUM(COALESCE(transaction_costs, 0)) AS total_shop_costs
```

### Margin (Marge)
```sql
-- From bt.daily_standup_metrics_category
SUM(marge) AS margin

-- Calculated
SUM(COALESCE(click_revenue, 0)) + SUM(COALESCE(transaction_costs, 0)) AS margin
```

## Performance Metrics

### ROAS (Return on Ad Spend)
Shop revenue divided by shop costs. **Only valid for shops that share data (`shop_deelt_data = 1`).**

```sql
-- Linked ROAS (recommended)
CASE
  WHEN SUM(COALESCE(click_revenue, 0)) + SUM(COALESCE(transaction_costs, 0)) > 0
  THEN SUM(revenue_excl) / (SUM(COALESCE(click_revenue, 0)) + SUM(COALESCE(transaction_costs, 0)))
  ELSE 0
END AS linked_roas

-- From bt.daily_standup_metrics_category
SUM(linked_revenue_excl_affiliates) / NULLIF(SUM(linked_costs_excl_affiliates), 0) AS roas
```

### ROI (Return on Investment)
```sql
-- From bt.daily_standup_metrics_category
SUM(omzet_total) / NULLIF((SUM(omzet_total) - SUM(marge)), 0) AS roi
```

### Revenue per Click (Rev/Click)
```sql
-- From bt.cpa_outclicks_transactional
CASE
  WHEN COUNT(DISTINCT stats_id_stat) > 0
  THEN SUM(revenue_excl) / COUNT(DISTINCT stats_id_stat)
  ELSE 0
END AS rev_per_click

-- From bt.daily_standup_metrics_category
SUM(linked_revenue_excl_affiliates) / NULLIF(SUM(linked_clicks_excl_affiliates), 0) AS rev_click
```

### eCPC (Effective Cost per Click)
```sql
SUM(omzet_total_excl_affiliates) / NULLIF((SUM(outclicks_excl_affiliates) + SUM(bvb_clicks)), 0) AS ecpc
```

## Visitor Metrics

### OPB (Omzet per Bezoeker / Revenue per Visit)
```sql
-- From bt.daily_standup_metrics_category
SUM(omzet_visit) / NULLIF(SUM(visits), 0) AS opb
```

### MPB (Marge per Bezoeker / Margin per Visit)
```sql
SUM(marge) / NULLIF(SUM(visits), 0) AS mpb
```

### CTR (Click-Through Rate)
Percentage of visits that result in outclicks.

```sql
-- Standard CTR
(SUM(bvb_clicks_visit) + SUM(outclicks_visit_stats)) / NULLIF(CAST(SUM(visits) AS FLOAT), 0) AS ctr

-- True CTR (only counting visitors who click)
SUM(true_ctr_clicks_visit) / NULLIF(CAST(SUM(visits) AS FLOAT), 0) AS true_ctr
```

### Bounce Rate
Percentage of visits without product clicks.

```sql
SUM(bounce_clicks_visit) / NULLIF(CAST(SUM(visits) AS FLOAT), 0) AS bounce_rate
```

## Conversion Metrics

### CVR (Conversion Rate)
Transactions divided by outclicks.

```sql
-- From bt.cpa_outclicks_transactional
SUM(transactions) / NULLIF(CAST(COUNT(DISTINCT stats_id_stat) AS FLOAT), 0) AS cvr

-- From bt.daily_standup_metrics_category
SUM(transactions_excl_affiliates) / NULLIF(CAST(SUM(linked_clicks_excl_affiliates) AS FLOAT), 0) AS cvr
```

### AOV (Average Order Value)
```sql
SUM(linked_revenue_excl_affiliates) / NULLIF(SUM(linked_transactions_excl_affiliates), 0) AS aov
```

### Transactions
```sql
-- Count transactions
SUM(transactions) AS total_transactions

-- Count linked transactions (with UUID)
SUM(transactions_with_uuid) AS linked_transactions
```

## Click Metrics

### Outclicks
Clicks from Beslist to shop websites.

```sql
-- Count unique outclicks
COUNT(DISTINCT stats_id_stat) AS outclicks

-- From aggregated table
SUM(outclicks) AS outclicks
```

### BvB Clicks (WW / Shopping Cart Clicks)
Clicks within Beslist's shopping cart (Winkelwagen).

```sql
SUM(bvb_clicks) AS ww_clicks
```

## Revenue Split

### WW Percentage
Percentage of revenue from Winkelwagen vs CPR.

```sql
SUM(ww_revenue) / NULLIF((SUM(cpc_revenue) + SUM(ww_revenue)), 0) AS ww_percentage
```

### CPR vs Affiliate vs WW Revenue
```sql
SUM(cpc_revenue) AS cpr_revenue
SUM(affiliate_revenue) AS affiliate_revenue
SUM(ww_revenue) AS ww_revenue
```

## Label-based Metrics

### Outclicks by Billing Label
```sql
SUM(cpa_label_outclicks) AS cpa_outclicks
SUM(cpa_cpc_label_outclicks) AS cpa_cpc_outclicks
SUM(t3_fallback_label_outclicks) AS t3_fallback_outclicks
```

### Revenue by Billing Label
```sql
SUM(cpa_label_revenue) AS cpa_revenue
SUM(cpa_cpc_label_revenue) AS cpa_cpc_revenue
SUM(t3_fallback_label_revenue) AS t3_fallback_revenue
```

## Complete Example: Monthly Performance Report

```sql
SELECT
  dat.year_month_number,
  chan.marketing_channel,

  -- Revenue
  SUM(tac.revenue_excl) AS shop_revenue,
  SUM(COALESCE(tac.click_revenue, 0)) + SUM(COALESCE(tac.transaction_costs, 0)) AS shop_costs,

  -- Clicks & Transactions
  COUNT(DISTINCT tac.stats_id_stat) AS outclicks,
  SUM(tac.transactions) AS transactions,

  -- Performance
  CASE
    WHEN SUM(COALESCE(tac.click_revenue, 0)) + SUM(COALESCE(tac.transaction_costs, 0)) > 0
    THEN SUM(tac.revenue_excl) / (SUM(COALESCE(tac.click_revenue, 0)) + SUM(COALESCE(tac.transaction_costs, 0)))
    ELSE 0
  END AS roas,

  CASE
    WHEN COUNT(DISTINCT tac.stats_id_stat) > 0
    THEN SUM(tac.revenue_excl) / COUNT(DISTINCT tac.stats_id_stat)
    ELSE 0
  END AS rev_per_click,

  SUM(tac.transactions)::FLOAT / NULLIF(COUNT(DISTINCT tac.stats_id_stat), 0) AS cvr

FROM bt.cpa_outclicks_transactional tac
JOIN datamart.dim_date dat ON date(tac.date) = date(dat.date)
LEFT JOIN chan_deriv.ref_channel_derivation_stats chan
  ON tac.aff_id = chan.aff_id AND tac.channel_id = chan.channel_id

WHERE tac.actual_ind = 1
  AND tac.deleted_ind = 0
  AND tac.label NOT IN ('cpa_after_180_days', 'rejected_click')
  AND tac.uuid_linked = 1
  AND tac.shop_deelt_data = 1
  AND date(tac.date) >= '2025-01-01'

GROUP BY dat.year_month_number, chan.marketing_channel
ORDER BY dat.year_month_number, chan.marketing_channel
```
